개인정보처리방침

시행일: 2026-09-27

macmini-rclone은 소유자 1인이 자신의 Google Drive를 다루기 위해 만든 개인용 도구입니다.

  • 접근하는 데이터: 소유자 본인의 Google Drive 파일 목록과 파일 내용(업로드·삭제·목록 조회에 한함).
  • 사용 목적: 소유자의 작업 파일을 지정된 Drive 폴더로 옮기고, 업로드가 정확한지 확인하는 데에만 사용합니다.
  • 저장: 인증 토큰은 소유자의 Mac mini 로컬 파일에만 저장되며, 외부 서버로 전송하지 않습니다.
  • 공유: 어떤 데이터도 제3자에게 제공·판매·공유하지 않습니다.
  • 철회: Google 계정 설정의 「타사 연결」에서 언제든지 접근 권한을 삭제할 수 있습니다.

Google API에서 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

Privacy Policy (English)

macmini-rclone is a personal tool used only by its owner to manage the owner's own Google Drive. It accesses the owner's Drive files solely to upload, delete and list files in designated folders. Tokens are stored only on the owner's local machine and are never sent to any third-party server. No data is sold, shared or transferred to anyone. Access can be revoked at any time from the Google Account "Third-party connections" page. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
